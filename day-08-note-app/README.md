# Not Kayıt Uygulaması

Tarayıcı tabanlı, kurulum gerektirmeyen bir not kayıt uygulaması. Notlarınızı başlık ve içerik ile kaydedebilir, arayabilir, düzenleyebilir ve silebilirsiniz. Tüm veriler tarayıcınızda yerel olarak saklanır (localStorage).

## Özellikler

- Not ekleme (başlık + içerik)
- Not listesini görüntüleme
- Arama ile not filtreleme
- Not düzenleme (düzenle butonu)
- Tekil not silme
- Tüm notları silme
- Tarih damgası (oluşturma/güncelleme)
- localStorage ile sayfa yenilendiğinde veri kalıcılığı
- Kurulum gerektirmez — doğrudan tarayıcıda çalışır

## Kullanılan Teknolojiler

- HTML5
- CSS3
- Vanilla JavaScript
- [Tailwind CSS](https://tailwindcss.com) (CDN ile)

## Yerel Çalıştırma

Proje klasöründeki `index.html` dosyasını çift tıklayarak herhangi bir modern web tarayıcısında açabilirsiniz. Sunucu kurulumu gerekmez.

```bash
cd day-08-note-app
open index.html   # macOS
# veya
xdg-open index.html # Linux
```
