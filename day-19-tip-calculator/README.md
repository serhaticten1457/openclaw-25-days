# Bahşiş Hesaplayıcı

Tarayıcı tabanlı, kurulum gerektirmeyen bir bahşiş (tip) hesaplayıcısıdır. Hesap tutarı, bahşiş yüzdesi ve kaç kişiye bölüneceğini girerek toplam tutarı ve kişi başına düşen miktarı hesaplar.

## Özellikler

- Hesap tutarı girişi
- Önceden tanımlanmış bahşiş yüzdesi seçenekleri (%15, %18, %20, %25)
- Özel yüzde girişi
- Kişi sayısı girişi (hesabı bölme)
- Bahşiş miktarı, toplam tutar ve kişi başına tutar gösterimi
- Anlık hesaplama
- Kurulum gerektirmez — doğrudan tarayıcıda çalışır

## Kullanılan Teknolojiler

- HTML5
- CSS3
- Vanilla JavaScript
- [Tailwind CSS](https://tailwindcss.com) (CDN ile)

## Yerel Çalıştırma

Proje klasöründeki `index.html` dosyasını çift tıklayarak herhangi bir modern web tarayıcısında açabilirsiniz. Sunucu kurulumu gerekmez.

```bash
cd day-19-tip-calculator
open index.html   # macOS
# veya
xdg-open index.html # Linux
```
