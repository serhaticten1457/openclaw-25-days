# Geri Sayım Zamanlayıcısı

Tarayıcı tabanlı, kurulum gerektirmeyen bir geri sayım zamanlayıcısıdır. Bir hedef tarih ve saat seçerek geriye doğru sayım yapabilirsiniz.

## Özellikler

- Hedef tarih ve saat seçimi (datetime-local)
- Gün, saat, dakika, saniye olarak ayrı ayrı gösterim
- Başlat / Durdur işlevi
- Sıfırlama (tüm süreyi temizler)
- Görsel ilerleme çemberi
- Hedef tarihe ulaşıldığında ekran mesajı ve tarayıcı bildirimi
- Kurulum gerektirmez — doğrudan tarayıcıda çalışır

## Kullanılan Teknolojiler

- HTML5
- CSS3
- Vanilla JavaScript
- [Tailwind CSS](https://tailwindcss.com) (CDN ile)

## Yerel Çalıştırma

Proje klasöründeki `index.html` dosyasını çift tıklayarak herhangi bir modern web tarayıcısında açabilirsiniz. Sunucu kurulumu gerekmez.

```bash
cd day-13-countdown-timer
open index.html   # macOS
# veya
xdg-open index.html # Linux
```
