# Pomodoro Zamanlayıcısı

Basit, tek dosyalı ve tarayıcı tabanlı bir Pomodoro (Çalışma/Mola) zamanlayıcısıdır. Odaklanmanı artırır ve düzenli molalarla üretkenliğini destekler.

## Özellikler

- Çalışma, kısa mola ve uzun mola modları
- Özelleştirilebilir süreler (dakika cinsinden)
- Görsel geri sayım dairesi
- Tarayıcı bildirimi desteği
- Tamamlanan tur sayacı
- Kurulum gerektirmez — doğrudan tarayıcıda çalışır

## Kullanılan Teknolojiler

- HTML5
- CSS3
- Vanilla JavaScript
- [Tailwind CSS](https://tailwindcss.com) (CDN ile)

## Yerel Çalıştırma

Proje klasöründeki `index.html` dosyasını çift tıklayarak herhangi bir modern web tarayıcısında açabilirsiniz. Sunucu kurulumu gerekmez.

```bash
# Klasöre gir
cd day-01-pomodoro-timer

# index.html'i tarayıcıda aç
open index.html   # macOS
# veya
xdg-open index.html # Linux
```
