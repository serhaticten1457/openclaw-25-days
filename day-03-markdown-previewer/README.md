# Markdown Önizleyici

Tarayıcı tabanlı, kurulum gerektirmeyen bir Markdown önizleyicisi. Yazarken anında HTML önizlemesini görebilir, metni veya oluşturulan HTML'i kopyalayabilirsiniz.

## Özellikler

- Canlı Markdown → HTML önizleme
- GFM (GitHub Flavored Markdown) desteği
- Kalın, italik, liste, alıntı, kod bloğu, başlık, bağlantı
- Kod bloğu içeriğiyle birlikte görünüm
- Editör ve önizleme arasında senkronize scroll
- Tek tıkla Markdown veya HTML'i panoya kopyalama
- Kurulum gerektirmez — doğrudan tarayıcıda çalışır

## Kullanılan Teknolojiler

- HTML5
- CSS3
- Vanilla JavaScript
- [marked.js](https://marked.js.org) (CDN ile)
- [Tailwind CSS](https://tailwindcss.com) (CDN ile)

## Yerel Çalıştırma

Proje klasöründeki `index.html` dosyasını çift tıklayarak herhangi bir modern web tarayıcısında açabilirsiniz. Sunucu kurulumu gerekmez.

```bash
cd day-03-markdown-previewer
open index.html   # macOS
# veya
xdg-open index.html # Linux
```
