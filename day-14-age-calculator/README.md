# Yaş Hesaplayıcı

Tarayıcı tabanlı, kurulum gerektirmeyen bir yaş hesaplayıcısıdır. Doğum tarihinizi girerek yaşınızı yıl, ay, hafta ve gün cinsinden öğrenebilirsiniz.

## Özellikler

- Doğum tarihi seçimi (date input)
- Yaşı yıl, ay ve gün olarak gösterme
- Toplam yaşadığınız gün ve hafta sayısı
- Sonraki doğum gününe kalan süre
- Anlık hesaplama (tarih seçildiğinde otomatik güncellenir)
- Gelecek tarih seçimi engelleniyor
- Kurulum gerektirmez — doğrudan tarayıcıda çalışır

## Kullanılan Teknolojiler

- HTML5
- CSS3
- Vanilla JavaScript
- [Tailwind CSS](https://tailwindcss.com) (CDN ile)

## Yerel Çalıştırma

Proje klasöründeki `index.html` dosyasını çift tıklayarak herhangi bir modern web tarayıcısında açabilirsiniz. Sunucu kurulumu gerekmez.

```bash
cd day-14-age-calculator
open index.html   # macOS
# veya
xdg-open index.html # Linux
```
