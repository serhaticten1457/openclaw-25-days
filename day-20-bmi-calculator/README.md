# VKİ Hesaplayıcı

Tarayıcı tabanlı, kurulum gerektirmeyen bir Vücut Kitle Endeksi (VKİ/BMI) hesaplayıcısıdır. Boy ve kilo bilgilerinizi girerek endeksinizi ve kategorinizi öğrenebilirsiniz.

## Özellikler

- Boy (cm) ve kilo (kg) girişi
- VKİ hesaplama (kg/m²)
- Kategori gösterimi (ciddi zayıf, zayıf, normal, fazla kilolu, obez sınıfları)
- Görsel aralık çubuğu
- Her kategori için sağlık açıklaması
- Kurulum gerektirmez — doğrudan tarayıcıda çalışır

## Kullanılan Teknolojiler

- HTML5
- CSS3
- Vanilla JavaScript
- [Tailwind CSS](https://tailwindcss.com) (CDN ile)

## Yerel Çalıştırma

Proje klasöründeki `index.html` dosyasını çift tıklayarak herhangi bir modern web tarayıcısında açabilirsiniz. Sunucu kurulumu gerekmez.

```bash
cd day-20-bmi-calculator
open index.html   # macOS
# veya
xdg-open index.html # Linux
```

## Sağlık Uyarısı

VKİ sadece bir screening aracıdır ve sağlık durumunuzu tam olarak yansıtmayabilir. Tıbbi tavsiye için bir sağlık profesyoneline danışın.
