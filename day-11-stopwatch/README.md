# Kronometre (Stopwatch)

Tarayıcı tabanlı, kurulum gerektirmeyen bir kronometre uygulaması. Zamanlayıcıyı başlatabilir, durdurabilir, tur kayıtları alabilir ve sıfırlayabilirsiniz.

## Özellikler

- Başlat / Durdur işlevi
- Tur kayıtları (her turun ayrı zamanı)
- Sıfırlama (tüm süre ve turları temizler)
- Çeyrek saniyelik hassasiyet (MM:SS.t formatı)
- Görsel ilerleme çemberi
- Durum etiketi (Çalışıyor / Durduruldu)
- Kurulum gerektirmez — doğrudan tarayıcıda çalışır

## Kullanılan Teknolojiler

- HTML5
- CSS3
- Vanilla JavaScript
- [Tailwind CSS](https://tailwindcss.com) (CDN ile)

## Yerel Çalıştırma

Proje klasöründeki `index.html` dosyasını çift tıklayarak herhangi bir modern web tarayıcısında açabilirsiniz. Sunucu kurulumu gerekmez.

```bash
cd day-11-stopwatch
open index.html   # macOS
# veya
xdg-open index.html # Linux
```
