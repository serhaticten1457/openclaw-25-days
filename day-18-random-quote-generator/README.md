# Rastgele Alıntı Üreticisi

Tarayıcı tabanlı, kurulum gerektirmeyen bir alıntı üreticisidir. Her klikte yeni bir ilham alıntısı gösterir, kategorilere göre filtrelenebilir ve kopyalanabilir.

## Özellikler

- Rastgele alıntı gösterme
- 4 kategori: Hepsi, Motivasyon, Başarı, Bilgelik, Yaşam
- Kategori filtresi
- Alıntıyı panoya kopyalama (yazarla birlikte)
- Basit fade animasyonu
- Yerel alıntı veritabanı (harici API gerekmez)
- Kurulum gerektirmez — doğrudan tarayıcıda çalışır

## Kullanılan Teknolojiler

- HTML5
- CSS3
- Vanilla JavaScript
- [Tailwind CSS](https://tailwindcss.com) (CDN ile)

## Yerel Çalıştırma

Proje klasöründeki `index.html` dosyasını çift tıklayarak herhangi bir modern web tarayıcısında açabilirsiniz. Sunucu kurulumu gerekmez.

```bash
cd day-18-random-quote-generator
open index.html   # macOS
# veya
xdg-open index.html # Linux
```
