# QR Kod Oluşturucu

Tarayıcı tabanlı, kurulum gerektirmeyen bir QR kod üreticisidir. Metin veya URL'den anında QR kod oluşturur ve PNG olarak indirebilirsiniz.

## Özellikler

- Metin veya URL'den QR kod üretme
- Özelleştirilebilir boyut (200×200, 300×300, 400×400, 500×500 px)
- QR kod rengi seçimi
- Yüksek hata düzeltme seviyesi (Level H)
- Tek tıkla PNG olarak indirme
- Anlık önizleme
- Kurulum gerektirmez — doğrudan tarayıcıda çalışır

## Kullanılan Teknolojiler

- HTML5
- CSS3
- Vanilla JavaScript
- [QRCode.js](https://davidshimjs.github.io/qrcodejs/) (CDN ile)
- [Tailwind CSS](https://tailwindcss.com) (CDN ile)

## Yerel Çalıştırma

Proje klasöründeki `index.html` dosyasını çift tıklayarak herhangi bir modern web tarayıcısında açabilirsiniz. Sunucu kurulumu gerekmez.

```bash
cd day-10-qr-code-generator
open index.html   # macOS
# veya
xdg-open index.html # Linux
```
