# Harf Dönüştürücü

Tarayıcı tabanlı, kurulum gerektirmeyen bir metin harf biçimi dönüştürücüsüdür. Yazdığınız metni farklı harf stillerine çevirebilirsiniz.

## Özellikler

- BÜYÜK HARF (UPPER CASE)
- küçük harf (lower case)
- Başlık Harfi (Title Case)
- Cümle harfi (Sentence case)
- camelCase
- PascalCase
- snake_case
- kebab-case
- CONSTANT_CASE
- Anlık dönüşüm (yazınca sonuç güncellenir)
- Sonucu panoya kopyalama
- Kurulum gerektirmez — doğrudan tarayıcıda çalışır

## Kullanılan Teknolojiler

- HTML5
- CSS3
- Vanilla JavaScript
- [Tailwind CSS](https://tailwindcss.com) (CDN ile)

## Yerel Çalıştırma

Proje klasöründeki `index.html` dosyasını çift tıklayarak herhangi bir modern web tarayıcısında açabilirsiniz. Sunucu kurulumu gerekmez.

```bash
cd day-22-case-converter
open index.html   # macOS
# veya
xdg-open index.html # Linux
```
