# Metin Analizi

Tarayıcı tabanlı, kurulum gerektirmeyen bir metin analiz aracıdır. Girilen metnin karakter, kelime, cümle, paragraf sayısını ve okuma süresini hesaplar. Ayrıca en sık kullanılan kelimeleri listeler.

## Özellikler

- Karakter sayısı (boşluklu ve boşluksuz)
- Kelime sayısı
- Cümle sayısı
- Paragraf sayısı
- Tahmini okuma süresi (dakika)
- En sık kullanılan 10 kelime ve frekans grafiği
- Örnek metin yükleme
- Metni panoya kopyalama
- Anlık analiz (yazınca sonuç güncellenir)
- Yerel olarak çalışır, veri sunucuya çıkmaz
- Kurulum gerektirmez — doğrudan tarayıcıda çalışır

## Kullanılan Teknolojiler

- HTML5
- CSS3
- Vanilla JavaScript
- [Tailwind CSS](https://tailwindcss.com) (CDN ile)

## Yerel Çalıştırma

Proje klasöründeki `index.html` dosyasını çift tıklayarak herhangi bir modern web tarayıcısında açabilirsiniz. Sunucu kurulumu gerekmez.

```bash
cd day-16-text-analyzer
open index.html   # macOS
# veya
xdg-open index.html # Linux
```
