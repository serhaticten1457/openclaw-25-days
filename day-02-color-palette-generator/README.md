# Renk Paleti Üreticisi

Tarayıcı tabanlı, kurulum gerektirmeyen bir renk paleti üreticisi. Kendi renk şemanızı oluşturun, değerleri kopyalayın ve projelerinizde kullanın.

## Özellikler

- 4 farklı palet türü: Rastgele, Monokromatik, Benzer Renk, Tamamlayıcı
- Özelleştirilebilir başlangıç rengi
- Renk sayısı ayarı (3–8 arası)
- Her bir rengi veya tüm paleti panoya kopyalama
- Kontrast uyumlu metin rengi otomatik seçimi
- Görsel palet önizleme ve renk değerleri listesi

## Kullanılan Teknolojiler

- HTML5
- CSS3
- Vanilla JavaScript
- [Tailwind CSS](https://tailwindcss.com) (CDN ile)

## Yerel Çalıştırma

Proje klasöründeki `index.html` dosyasını çift tıklayarak herhangi bir modern web tarayıcısında açabilirsiniz. Sunucu kurulumu gerekmez.

```bash
cd day-02-color-palette-generator
open index.html   # macOS
# veya
xdg-open index.html # Linux
```
